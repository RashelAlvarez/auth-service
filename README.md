
## Microservicio de autenticación desarrollado en Laravel, JWT, PostgreSQL y Docker 

Este microservicio permite la autenticación y el registro de usuarios mediante JSON Web Tokens (JWT).


## Tecnologías Usadas 💻

- Laravel para la creación del microservicio.
- PostgreSQL para la base de datos.
- Docker para la dockerización del microservicio y la base de datos.
- JWT para la autenticación.
- Postman para probar el API.
